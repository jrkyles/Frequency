# Contributing to Frequency

Thank you for considering contributing to Frequency! Your help is appreciated. This project is a work in progress, so contributions are especially valuable.

## How to Contribute
- **Bug Reports & Feature Requests:** Please use GitHub Issues.
- **Pull Requests:** Fork the repo, create a feature branch, and submit a PR. Describe your changes clearly.
- **Code Style:** Follow the existing code style and conventions. Use Prettier and ESLint if available.
- **Tests:** Add or update tests if possible.

## Code of Conduct
Be respectful and constructive. All interactions should be professional and inclusive.

---

*This project is actively being developed. Expect rapid changes!*
