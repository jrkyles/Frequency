# Contributing to Frequency

Thank you for your interest in contributing. This project is a work in progress and changes are ongoing.

## How to Contribute
- Report bugs or request features using GitHub Issues.
- Fork the repository, create a branch, and submit a pull request. Please describe your changes clearly.
- Follow the existing code style and conventions.
- Add or update tests if possible.

## Code of Conduct
Please be respectful and constructive in all interactions.
